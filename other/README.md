# Other / เอกสารและไฟล์ประกอบ

เอกสารและไฟล์ประกอบที่ไม่ใช่ lesson หรือ exercise — เนื้อหาการสอนเก็บใน `lessons/` และ `exercises/` เสมอ ที่เหลือใส่ไว้ที่นี่

| โฟลเดอร์ | ไว้ทำอะไร |
|----------|-----------|
| [assets/](assets/) | รูปภาพและแผนภาพที่ lesson/exercise อ้างถึง |
| [datasets/](datasets/) | ข้อมูลตัวอย่างของ lessons/exercises + case studies (ชื่อไทยได้) |
| [slides/](slides/) | deck ประกอบการสอน หรือ pointer ไป deck ภายนอก |
| [docs/](docs/) | JD, instructor notes, คู่มือ credentials |
| [reference/](reference/) | สรุป/cheat sheet เช่น n8n 2026 rebrand + 2.x notes |
| [scripts/](scripts/) | สคริปต์ช่วยงาน + structure check |

ชื่อไฟล์ไทยใช้ได้ที่นี่เมื่อจำเป็น **ห้าม** เพิ่มโฟลเดอร์ระดับ top-level พี่น้องกับนี้ — ต่อโครงสร้างใต้ tree นี้แทน
