# Course description / JD

รายละเอียดคอร์สสำหรับประกาศ (source of truth: Obsidian `Courses/n8n-workflow-automation-L1.md`)

- **Audience:** ผู้ไม่เคยใช้ n8n, พนักงานออฟฟิศ, ทีม IT/HR/Marketing, นักพัฒนาที่อยากต่อ AI แบบ low-code
- **Outcomes:** สร้าง automation บน n8n ได้, ต่อ Google Workspace/LINE/AI providers จริง, สร้าง AI Agent (memory/tools/RAG/MCP/multi-agent) และ self-host ด้วย Docker + Cloudflare
- **Duration:** 3 วัน (25 หน่วย × 30–90 นาที) + 3 workshops และ challenge
- **Delivery:** อบรม onsite พร้อม lab; ผู้เรียนใช้ n8n instance ของตัวเอง (เตรียมให้ หรือ self-host ตาม SETUP.md)
- **Prerequisites:** บัญชี Google + LINE, Docker Desktop, โดมน + Cloudflare (สำหรับ self-host) — ดู [SETUP.md](../../SETUP.md)
