# Exercise 02 — เริ่มต้น Workflow แรก

## Goal
- สร้าง "01 - Firstflow" ด้วยตัวเอง: Manual Trigger แล้วส่งอีเมลด้วย Gmail

## Setup
1. เปิด n8n แล้วอยู่ที่หน้า Overview
2. ไฟล์เริ่มต้นอยู่ใน `starter/` (ถ้ามี); ไฟล์เฉลยอยู่ใน `solution/` — ห้ามเปิดก่อนลองเอง
1. สร้าง workflow ใหม่ + Add workflow
2. เพิ่ม Trigger manually
3. เพิ่ม Gmail: Send a message → เชื่อม credential (ถ้ายังไม่มี ทำ Unit 09 ก่อน)
4. กด Execute workflow แล้วเช็คกล่องจดหมาย
5. ตั้งชื่อ workflow แล้ว Save

## Check your work
- อีเมลถึง inbox และ execution แสดงสีเขียวบน canvas
