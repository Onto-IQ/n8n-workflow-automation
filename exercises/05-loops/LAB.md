# Exercise 05 — Loop การวนซ้ำ

## Goal
- ประมวลผลนักเรียน 3 คนทีละคนด้วย loop

## Setup
1. เปิด n8n แล้วอยู่ที่หน้า Overview
2. ไฟล์เริ่มต้นอยู่ใน `starter/` (ถ้ามี); ไฟล์เฉลยอยู่ใน `solution/` — ห้ามเปิดก่อนลองเอง
1. Import ไฟล์ solution/03-Flow-Control-Demo-Loop-V2.json (V2 = สคีมา n8n 2.x, มี 03-Flow-Control-Demo-Loop.json เวอร์ชันเก่าให้เทียบ)
2. Execute แล้วเปิด execution detail ดูรอบการวน
3. เพิ่ม node ในวง loop ให้ทำอะไรจริง เช่น เติม field greeting ต่อคน

## Check your work
- loop วนครบ 3 รอบ แล้วออกทาง done พร้อมข้อมูลครบทุกคน
