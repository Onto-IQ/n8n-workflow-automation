# Exercise 16 — Credential OpenRouter

## Goal
- เรียกโมเดล free แรกผ่าน OpenRouter จาก n8n

## Setup
1. เปิด n8n แล้วอยู่ที่หน้า Overview
2. ไฟล์เริ่มต้นอยู่ใน `starter/` (ถ้ามี); ไฟล์เฉลยอยู่ใน `solution/` — ห้ามเปิดก่อนลองเอง
1. Sign in openrouter.ai ด้วย Google
2. สร้าง key ชื่อ n8n Router Key พร้อม credit limit
3. สร้าง credential OpenRouter ใน n8n
4. เรียก meta-llama/llama-3.1-8b-instruct:free ด้วย prompt ทดสอบ
