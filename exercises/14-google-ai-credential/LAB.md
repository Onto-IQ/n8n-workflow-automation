# Exercise 14 — Credential Google AI Studio (Gemini)

## Goal
- Gemini credential พร้อมใช้ + บอท LINE ตอบกลับได้

## Setup
1. เปิด n8n แล้วอยู่ที่หน้า Overview
2. ไฟล์เริ่มต้นอยู่ใน `starter/` (ถ้ามี); ไฟล์เฉลยอยู่ใน `solution/` — ห้ามเปิดก่อนลองเอง
1. สร้าง API key ใน Google AI Studio (สร้าง project ชื่อ n8n-student-course)
2. สร้าง credential Google Gemini (Paas/API key) ใน n8n แล้ววาง key
3. Import ไฟล์ solution/01 - LINE Chat Gemini Model.json แล้วเลือก credential ให้ครบ
4. Activate แล้วทักหา OA ถาม "พี่จอย ช่วยอธิบาย n8n หน่อย" และถามชื่อตัวเองสองรอบเพื่อทดสอบ memory

## Check your work
- บอทตอบกลับและจำข้อมูลที่เล่าให้ฟังก่อนหน้าได้
