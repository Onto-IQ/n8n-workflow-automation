# Exercise 01 — n8n คืออะไร

## Goal
- ลงมือใช้ n8n ครั้งแรก: เข้าใจหน้าจอ และนำเข้า workflow จาก repo นี้

## Setup
1. เปิด n8n แล้วอยู่ที่หน้า Overview
2. ไฟล์เริ่มต้นอยู่ใน `starter/` (ถ้ามี); ไฟล์เฉลยอยู่ใน `solution/` — ห้ามเปิดก่อนลองเอง
1. เข้าสู่ระบบ n8n ของคุณ (Cloud หรือ self-host ตาม SETUP.md)
2. สำรวจ 3 จุด: Overview, Canvas, Nodes panel
3. นำเข้า workflow: เปิดไฟล์ .json ใน repo → คัดลอกทั้งหมด → วาง (Ctrl+V) บนผืน canvas ใหม่ (วิธีเร็วสุด) หรือใช้ Workflow → Import from File / Import from URL (Raw จาก GitHub)
4. ตั้งชื่อ workflow "My First Import" แล้วกด Save

## Check your work
- workflow ปรากฏในหน้า Overview เป็นรายการแรกของคุณ สถานะ inactive
