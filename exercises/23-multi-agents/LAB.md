# Exercise 23 — Multi-Agents: Linear vs Orchestration

## Goal
- รันทั้งสองแบบและอธิบายผลต่างได้ด้วยข้อมูล execution

## Setup
1. เปิด n8n แล้วอยู่ที่หน้า Overview
2. ไฟล์เริ่มต้นอยู่ใน `starter/` (ถ้ามี); ไฟล์เฉลยอยู่ใน `solution/` — ห้ามเปิดก่อนลองเอง
1. Import ทุกไฟล์จาก solution/ (05A, 05B และ 05B-Sub- ทั้ง 4 ตัว)
2. รัน 05A ด้วยคำร้องทดลอง (ฟอร์ม) แล้วเก็บผล
3. รัน 05B ด้วยคำร้องเดียวกัน — สังเกต QA Reviewer + loop
4. สร้างเคสที่นโยบายไม่ผ่าน แล้วเทียบพฤติกรรมสองแบบ
