# Exercise 24 — Big Bonus: สร้าง Flow ด้วย Agentic IDE

## Goal
- workflow ที่คุณแต่งเองถูกสร้างขึ้นโดย agent ใน IDE

## Setup
1. เปิด n8n แล้วอยู่ที่หน้า Overview
2. ไฟล์เริ่มต้นอยู่ใน `starter/` (ถ้ามี); ไฟล์เฉลยอยู่ใน `solution/` — ห้ามเปิดก่อนลองเอง
1. ติดตั้ง n8n-mcp ใน IDE ที่คุณใช้ พร้อม n8n API key
2. สั่งให้ agent สร้าง workflow ตามจินตนาการ (Challenge จาก slide 229)
3. ตรวจ workflow ใน n8n แล้วปรับจุดที่ AI ทำผิด
4. เผยแพร่ screenshot ผลงานในกระดานสื่อสาร

## Check your work
- workflow ที่สร้างโดย IDE รันได้จริงใน n8n
