# Onto-IQ — topic family

Onto-IQ เป็นองค์กรกลุ่มหัวข้อ **AI** ใช้โครงสร้าง repo แบบเดียวกับ DataFabric-Academy ต่างกันที่ชุดหัวข้อ

หัวข้อทั่วไป: n8n / workflow automation (repo นี้), AI Agents with Microsoft Copilot Studio, Claude AI Agent for Business Productivity, Agentic AI Development with Google ADK + Python, Power Automate, Power Platform AI Builder

## แนวทางทำเนื้อหา

- อ่านง่ายสองภาษา: อธิบายภาษาไทย + คำสั่ง/ชื่อเครื่องมือเป็นอังกฤษ
- หน่วยแบบ hands-on จับคู่ `LESSON.md` + `LAB.md` ชื่อ `NN-slug` ตรงกันระหว่าง lessons/exercises
- คอร์ส multi-agent อาจใช้ workshop repo แยก โดย repo นี้เก็บ lessons + exercises
- deck ของวิทยากรอยู่ `other/slides/` (หรือชี้ path ใน `other/slides/README.md`)
- ชื่อ case study ไทยได้ใต้ `other/` เช่น `other/datasets/บริษัท สมสมัยงาน AI จำกัด/`
- สไลด์/เนื้อหาต้องไม่มีแบรนด์หรือเครื่องหมายลิขสิทธิ์ของบริษัทอบรมเดิมค้างไว้ (ดู CHANGELOG การล้าง deck ของ N8N-L1)
