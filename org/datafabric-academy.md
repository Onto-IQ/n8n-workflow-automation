# DataFabric-Academy — topic family

DataFabric-Academy เป็นองค์กรกลุ่มหัวข้อ **data platform** โครงสร้างโฟลเดอร์เหมือน Onto-IQ ทุกอย่าง ต่างที่หัวข้อ

หัวข้อทั่วไป: Power BI (modeling, DAX, Power Query, reports), Microsoft Fabric (Lakehouse, Warehouse, pipelines, semantic models, data science), SQL Server (queries, administration, performance, backup/restore, scripting)

## แนวทางทำเนื้อหา

- README สองภาษา: หัวข้อไทย + คำสั่งอังกฤษ
- Exercise นิยมมี starter SQL/notebooks และ datasets ใน `other/datasets/`
- Instructor deck เก็บใน `other/slides/` หรือชี้ path ใน `other/slides/README.md`
- Lesson/exercise slug เป็น ASCII; ชื่อไฟล์ไทยใช้ได้ใต้ `other/`
