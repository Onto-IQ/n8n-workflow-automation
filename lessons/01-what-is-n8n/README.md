## Objectives / วัตถุประสงค์
- อธิบายว่า n8n คือแพลตฟอร์มอะไรและต่างจากโค้ดพิมพ์เองอย่างไร
- เล่าความหมายของ rebrand ปี 2026 และยุทธศาสตร์ Agent-first
- เลือกรูปแบบการใช้งาน Cloud / Self-Host / VPS ให้เหมาะกับงาน

## Prerequisites / สิ่งที่ต้องมีก่อน
